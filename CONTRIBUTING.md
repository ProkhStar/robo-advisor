# Contributing

Obrigado por este interesse! Algumas regras básicas:

- Branches: usa `develop` para desenvolvimento e `main` apenas para releases/demos.
- Convenção de commits: `feat:`, `fix:`, `chore:`, `docs:`.
- Antes de submeter PRs, executa `pytest` e `flake8`.
- Para grandes mudanças, cria uma issue e descreve o plano.
